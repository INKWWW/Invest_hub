# V2 阅读来源切换修订 Spec

## 文档状态

- 阶段：V2 / X 信息收集与阅读
- 状态：**已批准（用户确认 2026-07-23）**
- 日期：2026-07-23
- 修订对象：[V2 X 指定博主信息收集与阅读 Spec](2026-07-22-v2-x-information-collection-and-reader-design.md)
- 修订原因：用户需要在阅读网页顶部直接切换 Discord 与 X；现有 V2 Spec 将 Discord/X 统一体验列为非目标，因此需明确该受限导航例外的边界。

## 1. 修订后的产品决定

普通阅读页顶部新增来源切换模块：`Discord | X`。

1. 切换模块同时存在于 `/discord` 与 `/x`；当前页面来源有明确的活动状态，两个入口分别跳转至自己的既有阅读路由。
2. 此模块仅用于来源导航。它不创建混合时间线、跨来源总结、跨来源作者/日期筛选、跨来源 checkpoint、跨来源证据关系或共享内容 DTO。
3. Discord Reader 继续只读取 Discord 安全投影；X Reader 继续只读取 X 安全投影。切换不转移、合并或暴露另一来源的原文、内部身份、任务状态、运行诊断或权限数据。
4. 模块面向普通 Reader；管理员控制台、来源配置、任务操作和权限边界不因该导航改变。
5. 桌面与 375px 宽度必须可操作、具有可见活动状态及可访问名称；不以纯色或图标作为唯一来源区分。

## 2. 与 V3 的边界

本修订是 V2 已有两套独立 Reader 的最小入口，不是 V3 的 Discord/X 统一体验。

仍然不属于 V2 的范围：

- Discord/X 混合或统一时间线；
- 跨来源观点、主题、博主或日期的综合总结；
- 一套共享的来源数据模型、任务、checkpoint、证据或权限投影；
- 对 Discord 已收口采集路线的恢复、变更或新增授权。

## 3. 实施与验收影响

在本修订和 V2 Plan 分别获批准后，V2 Plan 的 Reader Task 必须增加：

1. 一个可复用但仅导航的 Reader 顶部来源切换组件；
2. `/discord` 与 `/x` 两路上的活动状态、目的路由和普通用户可访问性测试；
3. 1280px 与 375px 的布局、键盘操作和无横向溢出测试；
4. 断言切换前后不出现跨来源原始正文、内部 ID、任务/Provider 诊断或未授权数据。

该变化只允许新增 Reader 导航与相关测试；不在本修订阶段写应用代码、改共享数据协议、运行真实 X 采集、应用远程 migration 或部署。

## 4. 对原 V2 Spec 的替换关系

本修订经批准后，仅对原 V2 Spec 的“Discord/X 统一体验或共享视觉重构”非目标增加上述最小导航例外。原 Spec 的来源事实隔离、独立任务/checkpoint、Reader 安全投影、权限边界、V3 范围以及所有真实采集/迁移/部署门禁继续完全有效。
