# X Reader 单博主帖子时间线展示设计

## 文档状态

- 阶段：X Reader 单博主阅读展示精简
- 状态：**已批准（用户确认 2026-08-08）**
- 日期：2026-08-08
- 关联：[X Reader 观点分类模块与原始帖子折叠设计](2026-08-07-x-reader-category-modules-and-collapsed-posts-design.md)

## 1. 问题与目标

当前单个博主区域复用了当日判断总结的分类模块，导致同一位博主的内容被拆成多个长模块，阅读路径冗长。原始帖子入口全部使用相同的“原始 X 帖子”标题，且当前默认折叠，读者无法快速区分帖子，也需要重复展开。

本次把单个博主内容改为“帖子时间线”：每个帖子是主要阅读单元，帖子下继续显示现有分析字段；当日判断总结继续保留现有三类分类模块。

## 2. 已确认方案

### 2.1 单博主展示结构

单个博主下删除“个股与产业观点”“市场结构观点”“投资策略与心态”三个分类模块。每个采集窗口按现有最新窗口优先顺序展示帖子，帖子下保留当前的博主观点、操作表述、条件、论据、引用帖观点和不确定性。

当窗口存在没有关联到具体帖子的旧版窗口观点时，继续以紧凑的普通观点列表展示，避免因为换布局丢失数据；这类内容不再使用三类分类模块。

### 2.2 帖子标题与时间信息

帖子标题使用“北京时间发帖时间 + 帖子类型”作为主区分信息：

- `08-08 03:05 · 原帖`
- `08-08 02:41 · 引用帖`
- `08-08 01:18 · 回复`
- `08-08 00:37 · 转发`

发帖时间取 `canonical_messages.occurred_at`，不使用采集时间、窗口截止时间或数据库写入时间。帖子类型取 `x_post_contexts.post_type`。时间缺失时退化为帖子类型或“原始 X 帖子”，并保留原始 X 链接。

### 2.3 展开状态与折叠图标

每个原始帖子使用原生 `<details>`，默认展开。summary 显示可旋转的明确折叠 icon、时间/类型和原始 X 链接；展开后继续使用当前字段顺序和文字，不生成新的摘要，不暴露内部 ID 或原始正文。

最新博主窗口继续默认展开，历史窗口继续默认折叠；当窗口没有逐帖分析时，现有空状态和未关联窗口观点继续按安全边界展示。

## 3. 数据与边界

Reader projection 仅补充现有数据库字段到 reader-safe DTO：`postedAt` 和 `postType`。不改变数据库结构，不修改采集、Prompt、Schema、LLM Provider、Worker、checkpoint、coverage、权限或生产数据。

普通 Reader API 只输出展示所需的时间、类型和原始链接，不输出内部 canonical ID、analysis ID、Prompt、Provider、运行诊断、本地路径或原始帖子正文。

## 4. 验收标准

1. 单个博主区域不再渲染三个观点分类模块，帖子成为主要内容单元。
2. 每个帖子下现有博主观点、操作表述、条件、论据、引用帖观点和不确定性字段均保留。
3. 原始帖子默认展开，并显示明确的折叠 icon；点击 icon 或 summary 可收起/展开。
4. 帖子 summary 优先显示北京时间发帖时间和帖子类型；时间缺失时有稳定降级文案。
5. 当日判断总结的三类分类模块不变；最新/历史窗口顺序和展开状态不变。
6. 375px 宽度下时间、类型、链接和长文本不横向溢出，键盘焦点可见。
7. Reader-safe API 和投影测试证明仅新增 `postedAt`、`postType` 等展示字段，不泄露内部字段。
8. 相关组件、投影、API、CSS 测试，lint、production build、`git diff --check` 和脱敏检查通过后，部署正式网页并完成 `/x` 验收。
