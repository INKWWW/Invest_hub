## Notable fixes

1. Supabase invite consumption now distinguishes `user` and `worker` purpose; Worker IDs are not forced through an auth-user foreign key.
2. Provider timeout cleanup closes stdin, terminates the whole process group and waits only within bounded cleanup windows.
3. Structured output rejects unknown/non-media/missing `media_source_message_ids`; the set must exactly equal the current chunk's unparsed media IDs.
4. Next.js build originally could not recognize the TypeScript 7 package layout. The control plane now pins TypeScript 5.9.3 and a matching parser, and `npm ci` reproduces the environment.
5. The E2E shell entry point rejects Python older than 3.11 instead of emitting a misleading worker import traceback.
