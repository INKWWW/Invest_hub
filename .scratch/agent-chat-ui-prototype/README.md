# Invest Hub Agent Chat UI Prototype

Throwaway prototype for comparing three Agent chat page structures. It has no persistence, authentication, database access, or real Agent calls.

Run from the repository root:

```bash
python3 -m http.server 4173 --directory .scratch/agent-chat-ui-prototype
```

Then open `http://127.0.0.1:4173/?variant=A`. Use the floating switcher or the left/right arrow keys to compare variants A, B, and C.

## Verdict

Variant A, "纸面工作台", was selected on 2026-08-11. Its simple two-column structure and Invest Hub visual language are the reference for the future Feature Contract; variants B and C remain only as discarded comparison material.
